# 🦅 Кордон-норма — Расчет штатной численности и потребности в ТСПК АПП (ГПС КР)

Веб-приложение на базе **Streamlit** и **SQLite** для автоматизации расчета штатной численности персонала и нормативной потребности в технических средствах пограничного контроля (ТСПК) на автомобильных пунктах пропуска (АПП) ГПС КР.

---

## 🚀 Основной функционал

* **Расчет штатной численности:** Автоматический расчет состава руководства и дежурных смен на основе коэффициентов подмены, типа графика (8h, 12h, 24h) и количества постов/кабин/полос.
* **Расчет потребности в ТСПК:** Динамический расчет необходимого количества оборудования (включая 10% НЗ) с группировкой по категориям важности (сверху вниз).
* **Интерактивный выбор моделей:** Возможность выбора конкретных моделей техники из встроенного справочника прямо в единой таблице.
* **Администрирование классификатора:** Встроенный интерфейс редактирования норм и справочника ТСПК с защитой паролем (пароль хранится в базе данных).
* **История расчетов:** Сохранение сгенерированных отчетов и параметров в SQLite.
